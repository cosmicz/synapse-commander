#+title: Synapse Commander
#+subtitle: Build your army. Manufacture its minds.
#+startup: overview

* Concept
A factory real-time strategy game about exploration, trade, combat and
manufactured intelligence. Factories build robot bodies and provision the
programs or reasoning minds that control them. Communication, computation
and memory are resources; deployed units must live with their instructions
until new ones can reach them.

Human–agent teams and autonomous teams are intended play modes. The aim is
useful cooperation through the game's mechanics, not privileged information
or arbitrary handicaps. Whether it works is a question to test.

* State of the project
Early backend only. The selected engine path is Recoil/Beyond All Reason. The
first loop (/Loop 0/) is a headless smoke: a scripted client sends one typed
intent through a loopback HTTP gateway, a game-side Lua bridge validates it and
orders one unit, and the movement is read back through the same gateway, with
a manifest and hash-chained ledger recorded from the start. It is a scripted
fixture, not autonomous play, not the Broken Relay mission and not a visual
demo. No playable build, benchmark result or release is claimed.
See [[file:DEVELOPMENT.org][development context]] and [[file:AGENTS.md][contribution rules]].
Loop 0 treats every nonempty typed argument object as =invalid_parameters= at
the gateway; it never forwards a raw engine command.

* Commands
- Tests (Python 3.13 standard library, no engine): =python3 -m unittest discover -s tests=
- Loop 0 headless smoke against staged engine artifacts:
  =python3 -m synapse_commander run-smoke --engine-dir ENGINE --data-dir DATA --game-dir BAR --out EVIDENCE --lock-dir LOCK --rig-commit SHA=
  (exit 0 only on PASS; see [[file:DEVELOPMENT.org::*Loop 0 native smoke][Loop 0 native smoke]]).

This repository is independent of event coordination and contains no tracker
database, private event records, engine binaries or BAR assets.
